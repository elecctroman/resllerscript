Reseller REST API

Bayileriniz için ürün listeleme, sipariş oluşturma ve bakiye yönetimi işlemlerini otomatikleştiren REST servisi. Bu sayfa api/openapi.yaml dosyasından üretilen Swagger dokümantasyonunu içermektedir.

Başlangıç

Kimlik Doğrulama

İsteklerinize X-API-Key başlığı veya Authorization: Bearer <token> formatında kimlik bilgisi ekleyin. HMAC imzası aktifleştirilen anahtarlar için aşağıdaki formülü kullanın:

signature = HMAC_SHA256(secret, timestamp + "\n" + METHOD + "\n" + PATH + "\n" + body)
X-Request-Timestamp: <unix epoch>
X-Signature: sha256=<signature>

Hız Limiti

Varsayılan limit dakika başına 120 istektir. API anahtarı bazında farklı sınırlar tanımlanabilir.
