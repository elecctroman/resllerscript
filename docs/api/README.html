Reseller API v1

Tam kapsamlı REST API ile ürün listeleme, sipariş oluşturma ve bakiye kontrolü işlemlerini otomatikleştirebilirsiniz. Kimlik doğrulaması Bearer token veya X-API-KEY başlıklarıyla yapılır.

Kimlik Doğrulama

{
  "email": "bayi@example.com",
  "password": "secret123"
}

Yanıt token alanı içerir. Bu token'ı Authorization: Bearer TOKEN şeklinde kullanabilirsiniz. Alternatif olarak API key ve secret ile erişim mümkündür.

Ürünleri Listeleme

curl -X GET "https://example.com/api/v1/products" \
  -H "X-API-KEY: YOUR_KEY" \
  -H "X-API-SECRET: YOUR_SECRET" \
  -H "X-CLIENT-DOMAIN: yoursite.com"

Sipariş Oluşturma

curl -X POST "https://example.com/api/v1/order/create" \
  -H "Content-Type: application/json" \
  -H "X-API-KEY: YOUR_KEY" \
  -H "X-API-SECRET: YOUR_SECRET" \
  -d '{
    "product_id": 24,
    "note": "Müşteri için",
    "external_reference": "ORDER-1001"
}'

Postman & SDK'lar

docs/api/postman_collection.json dosyasını Postman'e aktarabilirsiniz. PHP, Node.js ve Python istemci örnekleri integrations/sdk klasöründedir.
