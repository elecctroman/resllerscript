Reseller API v1.1

Tam kapsamlı REST API ile ürün listeleme, sipariş oluşturma ve bakiye kontrolü işlemlerini otomatikleştirebilirsiniz. Kimlik doğrulaması Authorization: Bearer TOKEN veya X-API-KEY başlıklarıyla yapılır.

Kimlik Doğrulama

{
  "email": "bayi@example.com",
  "password": "secret123"
}

Yanıt token alanı içerir. Bu token'ı Authorization: Bearer TOKEN şeklinde kullanabilirsiniz. Alternatif olarak API key ve secret ile erişim mümkündür.

Ürünleri Listeleme

curl -X GET "https://example.com/api/v1/products" \
  -H "X-API-KEY: YOUR_KEY" \
  -H "X-API-SECRET: YOUR_SECRET" \
  -H "X-CLIENT-DOMAIN: yoursite.com"

Sipariş Oluşturma

curl -X POST "https://example.com/api/v1/order/create" \
  -H "Content-Type: application/json" \
  -H "X-API-KEY: YOUR_KEY" \
  -H "X-API-SECRET: YOUR_SECRET" \
  -d '{
    "product_id": 24,
    "note": "Müşteri için",
    "external_reference": "ORDER-1001"
}'

Bakiye & Kullanıcı Bilgisi

curl -X GET "https://example.com/api/v1/balance" \
  -H "X-API-KEY: YOUR_KEY" \
  -H "X-API-SECRET: YOUR_SECRET"
curl -X GET "https://example.com/api/v1/user/info" \
  -H "X-API-KEY: YOUR_KEY" \
  -H "X-API-SECRET: YOUR_SECRET"

API Anahtarı Yönetimi

curl -X POST "https://example.com/api/v1/api-keys/create" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <TOKEN>" \
  -d '{"allowed_domains": ["example.com"], "allowed_ips": ["1.1.1.1"]}'
curl -X GET "https://example.com/api/v1/api-keys/list" \
  -H "Authorization: Bearer <TOKEN>"
