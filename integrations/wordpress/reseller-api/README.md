# Reseller API WooCommerce Bridge

This plugin connects your Lotus Reseller Panel to WooCommerce so dealers can import products, monitor balances and review API activity without leaving WordPress.

## Key features

* **API connection wizard** – store the panel URL and API key, then validate everything with a single click.
* **WooCommerce catalogue sync** – import reseller products into WooCommerce with optional percentage mark-up.
* **Balance and order insights** – pull the latest credit information and remote order history on demand.
* **Scheduled refresh** – run automatic catalogue refreshes hourly, twice daily or daily.

## Installation

1. Copy the entire `reseller-api` directory into your WordPress installation under `wp-content/plugins/`.
2. Activate **Reseller API WooCommerce Bridge** from the WordPress Plugins screen.
3. Visit **Reseller API → Settings** to enter your API URL and API key.
4. Click **Test Connection** to verify the credentials, then **Sync Products Now** to populate WooCommerce.

## Requirements

* WordPress 6.0 or newer
* WooCommerce 6.5 or newer
* PHP 7.4+
